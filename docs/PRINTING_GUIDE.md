# Community Local Printing Guide 🖨️
> **คู่มือการพิมพ์ธนบัตรสีไร้ตัวเลข สำหรับชุมชนและสหกรณ์ฐานราก**
> Protocol Standard Version: 1.0.0

---

## 1. ข้อกำหนดทางกายภาพและกระดาษ (Physical Paper Specifications)
1. **ชนิดกระดาษ:** แนะนำกระดาษใยฝ้ายผสมเยื่อไผ่ (Cotton-Bamboo Blend) น้ำหนัก **90 - 120 GSM** ทนทานต่อการเปียกน้ำ ละอองน้ำมันในตลาดสด และการพับซ้ำ
2. **ขนาดบัตรมาตรฐาน:** กว้าง 65 มม. × ยาว 125 มม. (กระชับมือ หยิบจ่ายคล่อง พกใส่กระเป๋าเสื้อได้ง่าย)
3. **การตัดขอบ:** ตัดมุมโค้งมน (Radius 3 มม.) เพื่อลดการพับหงิกงอที่มุม

## 3. ขั้นตอนการพิมพ์และเปิดใช้งาน (Step-by-Step Workflow)

### ขั้นตอนที่ 1: วางเงินค้ำประกันในระบบ (Collateral Deposit)
สหกรณ์ชุมชนหรือกลุ่มทุนท้องถิ่นต้องฝากเงินค้ำประกันเข้าสู่ Smart Contract `OfflineNoteSync` ในอัตราส่วนขั้นต่ำ **10 เท่า** ของมูลค่าที่จะพิมพ์ (Reserve Ratio 1000%)

### ขั้นตอนที่ 2: สุ่มสร้าง Token Hash แบบ Offline
ใช้สคริปต์สุ่ม Nonce และสร้าง JAB Code ในสภาพแวดล้อมแอร์แก็ป (Air-gapped) เพื่อความปลอดภัยสูงสุด

### ขั้นตอนที่ 3: ลงทะเบียนรหัสขึ้นบล็อกเชน (Batch Register)
นำชุด `TokenHash` ทั้งหมดที่สร้างขึ้น ส่งธุรกรรม `registerPhysicalNote()` ขึ้นสัญญาอัจฉริยะ (สามารถทำผ่าน L2 Batching เพื่อประหยัดค่าแก๊ส)

### ขั้นตอนที่ 4: พิมพ์และตัดจ่ายสู่ตลาด
พิมพ์ลงบนกระดาษด้วยเครื่องพิมพ์ระบบ Inkjet 6 สี หรือ Digital Offset หมึกกันน้ำ จากนั้นแจกจ่ายให้ร้านค้าสมาชิกและประชาชนนำไปใช้จับจ่ายในตลาดสดได้ทันที!
