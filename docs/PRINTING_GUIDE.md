# Community Local Printing Guide: Scratch Note Architecture 🖨️
> **คู่มือการพิมพ์ธนบัตรสีแบบบัตรขูด (Scratch Card) สำหรับชุมชนและสหกรณ์**
> Protocol Standard Version: 1.1.0 (Scratch-To-Sync & Visual Proof of Unspent)

---

## 1. ปรัชญาการออกแบบ: Visual Proof of Unspent (เช็กด้วยตาเปล่า ไม่ต้องง้อเน็ต)
การใช้แถบฟอยล์สีเงินปิดทับรหัส (Scratch-Off Layer) ช่วยแก้ปัญหาความเชื่อมั่นออฟไลน์:
- **แถบฟอยล์ยังสมบูรณ์ (Intact):** แสดงว่ารหัสลับภายในยังไม่เคยถูกเปิดเผย เงินสดมีมูลค่าเต็ม 100% ส่งต่อและทอนกันได้ไม่จำกัดรอบ
- **แถบฟอยล์ถูกขูดออกแล้ว (Scratched):** แสดงว่ารหัสด้านในถูกนำไปสแกนซิงค์เข้าออนไลน์แล้ว บัตรนี้สิ้นสภาพออฟไลน์ ห้ามรับชำระในตลาดสด

---

## 2. โครงสร้างกายภาพของธนบัตรบัตรขูด

```
========================= ด้านหน้า (Front Side) =========================
+-----------------------------------------------------------------------+
|  [แถบสีพื้นเต็มใบ: ส้ม 1 / เขียว 5 / ฟ้า 20 / ม่วง 100 TVEE]         |
|                                                                       |
|   +-------------------+                                               |
|   |  แถบฟอยล์สีเงินขูด  |   T-VEE SCRATCH CASH                        |
|   |  [ ซ่อน JAB Code  |   "Visual Proof of Unspent"                   |
|   |    และ Token Hash]|   *หากฟอยล์ยังไม่ถูกขูด = มีมูลค่าเต็ม 100%   |
|   +-------------------+   *ขูดแถบออกเฉพาะเมื่อต้องการซิงค์เข้ามือถือ  |
|                                                                       |
|   Serial No: TVEE-2026-XXXX         Vault Origin: 0x71A...9F          |
+-----------------------------------------------------------------------+

========================= ด้านหลัง (Back Side) ==========================
+-----------------------------------------------------------------------+
|  ข้อแนะนำการใช้งานสำหรับชุมชน:                                        |
|  1. ตรวจสอบแถบฟอยล์ด้านหน้า: ต้องไม่มีรอยถลอก รอยกรีด หรือรอยขูด     |
|  2. ส่งต่อ ทอน หมุนเวียนในตลาดสดได้เสรีเหมือนเงินสดปกติ               |
|  3. หากต้องการนำเงินเข้าบัญชีดิจิทัล ให้ขูดแถบฟอยล์ออก แล้วสแกนด้วยแอป |
|  4. หลังสแกนแล้ว กระดาษนี้จะกลายเป็นกระดาษเปล่า ไม่สามารถนำมาจ่ายได้  |
+-----------------------------------------------------------------------+
```

## 3. สเปกการผลิตเชิงเทคนิค (Manufacturing Specifications)

1. **วัสดุฐานบัตร (Substrate):** กระดาษอาร์ตการ์ด 2 หน้า 250 - 300 GSM หรือกระดาษคอตตอนผสม ทนต่อแรงขูด ไม่ทะลุ
2. **การเคลือบผิว (Surface Lamination):** เคลือบเงาแบบ UV Overprint วานิชบนจุดพิมพ์ JAB Code ก่อน เพื่อให้เวลาขูดเนื้อฟอยล์ออก จะลอกหลุดง่ายและไม่ทำลายเมทริกซ์สีด้านล่าง
3. **แถบฟอยล์ขูด (Scratch Foil):**
   * หมึกขูดซิลเวอร์ลาเท็กซ์ (Silver Latex Scratch-off Ink) ชนิดทึบแสง 100% หนา 30-40 ไมครอน
   * ป้องกันการส่องไฟทะลุ (Anti-transillumination) ป้องกันไม่ให้แอบถ่ายรหัสลับผ่านแสงไฟนีออน
4. **ขนาดมาตรฐาน:** กว้าง 54 มม. × ยาว 86 มม. (ขนาดเดียวกับบัตรประชาชน/บัตรเอทีเอ็ม พกพาใส่กระเป๋าสตางค์ได้ทันที)
